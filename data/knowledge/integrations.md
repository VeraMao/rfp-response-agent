# Integrations

## Data warehouses
Native connectors for Snowflake, Google BigQuery and Amazon Redshift on all plans.
Databricks is supported through a JDBC connector (beta).

## CRM connectors
Bi-directional Salesforce connector on all plans: sync accounts and opportunities
in both directions. HubSpot connector is read-only.

## API and webhooks
REST API on all plans. Rate limit: 100 requests per minute on Standard,
1,000 on Enterprise. Webhooks for alerts and report completion.
